# Mental Health Model Training

A Python-based Machine Learning project that explores student mental health data and trains regression models to predict a mental health score.

## Overview

This project uses student-related information such as study hours, age, daily usage, physical activity, sleep hours, and stress level to analyze patterns related to mental health.

The notebook includes data exploration, feature engineering, preprocessing, model training, and evaluation.

## Features

- Load student mental health data from a CSV file
- Explore the dataset using Pandas
- Generate descriptive statistics
- Analyze gender, country, academic level, and stress level
- Visualize categorical and numerical data
- Handle negative physical activity values
- Group countries into frequent countries and an `Other` category
- Apply feature engineering
- Encode categorical features
- Scale numerical features
- Split data into training and testing sets
- Build Machine Learning pipelines
- Train Linear Regression and Random Forest models
- Evaluate predictions using regression metrics
